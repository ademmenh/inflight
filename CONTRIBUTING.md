# Contributing

## Development

```bash
bun install
bun test        # run tests
bun run bench   # run benchmarks
bun run build   # compile typescript
```

## Pull Requests

1. Fork the repo
2. Create a feature branch
3. Make your changes
4. Run tests and benchmarks
5. Submit a PR
